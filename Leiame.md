# 🎓 Minhas Atividades em C - Faculdade

Bem-vindo(a) ao meu repositório! 👋

Este espaço foi criado para documentar, organizar e compartilhar todas as atividades, exercícios e projetos desenvolvidos durante as minhas aulas de programação em **C** na faculdade.

## 🎯 Qual o objetivo deste repositório?

A ideia principal aqui é registrar a minha evolução na lógica de programação. Mais do que apenas entregar os trabalhos da faculdade, eu utilizo este repositório como um ambiente de testes e aprimoramento. 

Muitas vezes, pego a atividade base pedida pelo professor e crio versões extras (como os arquivos `-Melhorada.c`), onde aplico conceitos que fui além para aprender, como:
- Sistemas de **validação de entrada** (evitando que os programas quebrem).
- Limpeza de buffer de teclado.
- Uso de operadores avançados (como aninhamento de ternários).
- Estruturas de repetição seguras.

## 📁 Como os códigos estão organizados?

O repositório é bem direto. Cada pasta representa um exercício ou módulo da faculdade.
Dentro delas, você normalmente encontrará:
1. O código base resolvendo o problema matemático/lógico.
2. Uma versão aprimorada com tratamento de erros e melhor experiência para o usuário (quando aplicável).

## 🛠️ Ferramentas Utilizadas
- **Linguagem:** C
- **Ambiente/Editor:** Visual Studio Code (VS Code)
- **Compilador:** GCC / MinGW
