# 🎓 My C Activities - College

Welcome to my repository! 👋

This space was created to document, organize, and share all the activities, exercises, and projects developed during my C programming classes at college.

## 🎯 What is the purpose of this repository?

The main idea here is to record my evolution in programming logic. More than just submitting college assignments, I use this repository as a testing and improvement environment. 

Often, I take the base activity requested by the professor and create extra versions (such as the `-Melhorada.c` files), where I apply concepts I went out of my way to learn, such as:

- **Input validation systems** (preventing programs from crashing).
- **Keyboard buffer clearing**.
- **Use of advanced operators** (like nested ternaries).
- **Safe loop structures**.

## 📁 How is the code organized?

The repository is pretty straightforward. Each folder represents a college exercise or module. Inside them, you will usually find:

1. The base code solving the mathematical/logical problem.
2. An improved version with error handling and a better user experience (when applicable).

## 🛠️ Tools Used

- **Language:** C
- **Environment/Editor:** Visual Studio Code (VS Code)
- **Compiler:** GCC / MinGW
